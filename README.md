# Tools for everyone

Public tools. **$0.** MIT. No store, no funnel, no account.

We invent a tool only when someone can use it without us. Then we put it on the internet.

## Tools now

| Tool | What it does |
|---|---|
| [Permit feed](permit-feed/) | Search sample building permits in the browser. No city-hall call. |
| [Windows ping](windows-ping/) | Small bottom-right Windows toast. No focus steal. Sound optional. |
| [PC install](pc-install/) | You name a program. `winget` installs it. No Settings → Apps. |

Site (after Pages is on): https://kawhooped.github.io/tools-for-everyone/

Repo: https://github.com/Kawhooped/tools-for-everyone

## Law

- One working tool beats a hundred sketches.
- Not a second Gumroad SKU. Not an HTML factory for money.
- Secrets stay off this repo.
